# اپ اندروید پنل صنعتی فرمالین (WebView)

این پروژه، فایل HTML پنل را داخل اپ اندروید اجرا می‌کند؛ برای نمایش خود پنل اتصال اینترنت لازم نیست. لینک‌های وب بیرونی، مثل سامانه آرشیو، در مرورگر گوشی باز می‌شوند.

## ساخت APK با GitHub

1. فایل ZIP پروژه را از حالت فشرده خارج کنید.
2. وارد GitHub شوید و یک مخزن جدید (Repository) بسازید.
3. تمام محتویات پوشه پروژه را در مخزن آپلود کنید؛ خود پوشه `formalin_webview_app` را به‌عنوان یک پوشه تو در تو آپلود نکنید. فایل `settings.gradle` باید در ریشه مخزن باشد.
4. از تب **Actions**، گردش‌کار **Build Android APK** را انتخاب کنید.
5. روی **Run workflow** بزنید و اجرای آن را تأیید کنید. با هر Push به شاخه `main` یا `master` نیز ساخت اجرا می‌شود.
6. پس از سبز شدن اجرا، وارد همان اجرای workflow شوید و از بخش **Artifacts** فایل `Formalin-Industrial-Panel-APK` را دانلود کنید.
7. ZIP مربوط به Artifact را باز کنید؛ فایل `app-debug.apk` داخل آن است. آن را به گوشی منتقل و نصب کنید. ممکن است اندروید برای نصب خارج از فروشگاه اجازه نصب از منبع مربوطه را بخواهد.

## نکات

- این خروجی APK آزمایشی (Debug) است و برای نصب و تست داخلی مناسب است.
- شناسه برنامه: `com.arianjalrang.formalin`
- نام برنامه: «پنل صنعتی فرمالین»
- آیکون گرد صنعتی به‌صورت وکتور اندروید در پروژه قرار دارد.
- برای تغییر پنل، فایل `app/src/main/assets/index.html` را جایگزین کنید و دوباره workflow را اجرا کنید.
